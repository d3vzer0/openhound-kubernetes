## About

OpenHound is a standardized framework for building OpenGraph collectors and converters. Built
on [DLT](https://dlthub.com/docs/intro) (Data Load Tool) and [Typer](https://typer.tiangolo.com/), it provides a
consistent workflow for collecting, processing, and converting data from any source into BloodHound-compatible graphs.
The OpenHound-kubernetes extension collects kubernetes cluster resources and transforms these into usable nodes and
edges for BloodHound. The Kubernetes collector is under active development, use at your own risk.
